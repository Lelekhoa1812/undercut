# Licensing decision

This initial repository package does **not** include an open-source license. That is intentional: publishing a license is a rights/redistribution decision for the owner, not a technical default to invent.

Before inviting general reuse, choose a license deliberately (for example MIT or Apache-2.0 if those terms suit the owner) and add its complete, accurate text as `LICENSE`, with any required attribution/notice. Update the README and release metadata accordingly. Do not label this code "MIT licensed" or "open source" until the actual license exists.

Repository visibility (public/private) and license (grant of rights) are distinct choices. Public source without an explicit license does **not** automatically grant reuse rights.
