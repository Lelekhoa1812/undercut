# Worked conversations

These examples are **illustrative dialogues**, not transcripts from an executed agent, not real code changes, and not evidence of actual tests. They show how to communicate under the Undercut skill.

- [Ambiguous form behavior](ambiguous-form.md): ask one decision-changing question
- [Known tiny change](tiny-fix.md): don't ask pointless questions
- [Unfamiliar codebase](unfamiliar-repo.md): inspect only what's needed
- [Bug reproduction](debugging.md): one hypothesis, one focused check
- [High-risk shortcut](risk-stop.md): don't sacrifice authorization or data
- [Incremental multi-feature request](sequencing.md): sequential vertical slices
- [Testing honesty](verification.md): report exact evidence and limits
